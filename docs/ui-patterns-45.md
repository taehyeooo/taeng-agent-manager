현재 앱의 화면과 코드를 살펴보고, 아래 45개 UI 패턴 중 기존 기능에 어울리는 것을 골라 실제로 적용해줘.

먼저 사용자가 버튼을 누른 뒤 반응을 알기 어려운 곳, 데이터를 기다리는 동안 화면이 비어 보이는 곳, 입력이나 선택이 불편한 곳을 찾아줘. 각 패턴은 적용 후보야. 45개를 전부 넣을 필요는 없어. 이미 자연스럽게 동작하는 부분은 유지하고, 앱에 없는 기능을 패턴 때문에 새로 만들지는 말아줘.

[적용할 때 지켜줘]
- 사용자 행동과 가장 가까운 곳에 피드백을 줘. 예를 들어 복사 버튼이 '복사됨'으로 바뀐다면 같은 내용의 토스트까지 띄울 필요는 없어.
- 성공 표시는 실제 작업이 성공한 뒤에 보여줘. 저장에 실패하면 로딩을 끝내고 입력한 내용은 유지해서 다시 시도할 수 있게 해줘.
- 기존 공통 컴포넌트와 디자인 규칙을 우선 사용해. 애니메이션은 짧게 유지하고 기기의 모션 줄이기 설정을 존중해.
- 일반적인 UI 개선은 직접 적용해줘. 새 기능 추가나 주요 화면 구조 변경이 필요한 항목은 이유와 함께 제안으로 남겨줘.
- 수정한 화면은 실행 가능한 범위에서 직접 확인해줘. 마지막에는 '화면 / 기존 불편 / 적용한 패턴 / 확인 결과'를 짧게 정리하고, 실행해서 확인하지 못한 부분도 알려줘.
