## MVP 개념 15개
기초 ① 프로세스와 메모리 ② 네트워크 왕복 지연 · DB ③ 인덱스와 B-Tree ④ 실행 계획 ⑤ N+1 ⑥ 커넥션 풀 ⑦ JDBC 배치 ·
캐시·동시성 ⑧ 캐시 ⑨ 분산 락 ⑩ 비동기(CompletableFuture) · 메시지 ⑭ Kafka · JVM·서버 ⑪ 힙과 GC ⑫ 스왑·OOM·CPU steal ·
성능 ⑬ p95·처리량·부하 테스트 · AI 백엔드 ⑮ Spring AI 2

## MVP 범위
포함: 학습 지도, 5단계 설명, 프로젝트 사례, 객관식·OX·원인 분석 문제, 오답 진단·복습 일정, 학습 기록, 텍스트 AI 튜터, 개념 그림·실제 화면·문제 속 그림
제외: 빈칸·기술 선택·서술형 자동 평가, 실전 모드, 음성, 면접, 다중 사용자, 배포
